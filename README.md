# Support Triage — классификация тональности клиентских обращений

Baseline-пайплайн на C# / ML.NET для классификации тональности русскоязычных обращений в службу поддержки. Классифицирует текст на `positive`, `negative`, `neutral` и формирует приоритизированный список тикетов для агента.

## Стек

- **C#** (.NET Framework 4.8)
- **ML.NET 1.5.4** — обучение и инференс
- **CsvHelper 30.0.1** — корректное чтение CSV с запятыми и кавычками в текстах
- **PowerShell 5.1+** — воспроизведение метрик одной командой

## Модель

- **Тренер:** `LbfgsMaximumEntropy` (мультиклассовая логистическая регрессия с L2-регуляризацией).
- **Признаки:** bag-of-words (`FeaturizeText` с TF-IDF) + длина текста (`TextLength`) + веса классов (`negative = 2.0, positive = 1.5, neutral = 1.0`).
- **Препроцессинг:** замена эмодзи и смайлов (`:)`, `)))`, `❤` и т.п.) на словарные токены перед подачей в модель.

Выбор `LbfgsMaximumEntropy` обоснован сравнением с `SdcaMaximumEntropy` и `NaiveBayes` — см. блок `=== Сравнение тренеров ===` в `otvet.txt`.

## Данные

- **Обучающие:** `rusentiment_preselected_posts.csv` — посты ВКонтакте с разметкой тональности (датасет **RuSentiment**, ~5812 записей после фильтрации).
- **Golden set:** `rusentiment_test.csv` — официальная тестовая выборка RuSentiment, не пересекается с обучающими данными.
- **Доменные:** `support_tickets_v2.csv` — ~85 размеченных обращений в поддержку (жалобы, вопросы, благодарности), собранные вручную.

Источник RuSentiment: https://github.com/searayeah/russian-sentiment-emotion-datasets

> **Важно:** CSV-файлы не хранятся в репозитории из-за размера. Скачайте их по ссылке выше (или соберите свои — формат: `label,text`, где `label` ∈ {`positive`, `negative`, `neutral`}). Положите в **любую** подпапку проекта — `run.ps1` найдёт их рекурсивно.
